# 올라가보카! (GoUpVoca) 📖🎮 Ai활용개발 게임 

**토익 단어 암기를 쉽고 재미있게!**  

올라가보카는 퀴즈 형식의 게임을 통해 토익 필수 단어를 효과적으로 학습할 수 있도록 제작된 모바일 게임입니다.

---

## 📌 프로젝트 개요  
### 🔹 왜 만들었나요?  
- 취업을 위해 **토익 점수의 중요성**이 커지는 상황에서,  
- 단순 암기가 아닌 **재미있는 학습 방법**이 필요하다고 생각했습니다.  
- 그래서 **게임 형식으로 단어를 익힐 수 있는 앱**을 개발하게 되었습니다.  

### 🎯 목표  
✅ **퀴즈 기반 학습**으로 단어 암기 효율 극대화  
✅ **난이도 조절 시스템**을 통한 맞춤형 학습  
✅ **간단한 조작**으로 누구나 쉽게 플레이 가능  

---

## 🎮 게임 기능  
### 1️⃣ **퀴즈 기반 게임 진행**  
- 주어진 한국어 뜻을 보고 **올바른 영어 단어 선택**  
- 3개의 목숨(❤️)을 가지고 시작하며, 틀리면 1개 감소  

### 2️⃣ **난이도 선택 기능**  
- **Easy, Normal, Hard** 모드 제공  
- 난이도별로 선택지 개수와 문제 유형이 다름  

### 3️⃣ **점수 시스템**  
- 정답 시 **10점** 획득, 최대 점수 **990점**  

### 4️⃣ **오답 복습 기능**  
- 틀린 단어를 저장하여 **게임 종료 후 오답 복습 가능**
